# AAHUB固件升级程序

一个具有现代科技感界面的ESP32固件升级工具,支持一键烧录多个固件文件到ESP32开发板。

## ✨ 功能特点

✅ **科技感界面** - 深色灰色主题,现代化设计风格  
✅ **无边框设计** - 现代化无边框窗口,可拖动标题栏移动  
✅ **安全关闭** - 升级过程中无法关闭程序,防止意外中断  
✅ **版本管理** - 在界面上显示固件版本号,可通过配置文件自由修改  
✅ **串口自动检测** - 自动扫描并列出可用串口  
✅ **配置文件管理** - 通过JSON文件灵活配置固件和地址  
✅ **实时进度** - 动态进度条和状态显示  
✅ **状态提示** - 清晰的成功/失败/警告提示  
✅ **多文件支持** - 支持同时烧录多个bin文件(bootloader、分区表、固件等)

## ⚙️ 配置说明

编辑 `config.json` 文件来配置你的固件信息:

```json
{
    "firmware_version": "v1.0.0",
    "baud_rate": 921600,
    "chip": "esp32",
    "update_log": [
        "• 修复了蓝牙连接稳定性问题",
        "• 优化了电源管理模块",
        "• 新增了自动对焦功能",
        "• 改进了温度补偿算法",
        "• 更新了用户界面显示效果"
    ],
    "firmware_files": [
        {
            "address": "0x1000",
            "file": "bootloader.bin",
            "description": "Bootloader"
        },
        {
            "address": "0x8000",
            "file": "partition-table.bin",
            "description": "分区表"
        },
        {
            "address": "0x10000",
            "file": "firmware.bin",
            "description": "主固件"
        }
    ]
}
```

### 配置项说明:

- **firmware_version**: 固件版本号 (会在界面顶部显示,可自由修改)
- **baud_rate**: 烧录波特率 (推荐921600,可选115200/460800/1500000)
- **chip**: 芯片类型 (esp32/esp32s2/esp32s3/esp32c3等)
- **update_log**: 更新日志列表 (在界面中央显示,每条以"•"开头)
- **firmware_files**: 固件文件列表
  - **address**: 烧录地址 (十六进制格式)
  - **file**: bin文件路径 (相对或绝对路径)
  - **description**: 文件描述 (可选)

### 常见地址配置:

| 文件 | 地址 | 说明 |
|------|------|------|
| bootloader.bin | 0x1000 | 引导加载程序 |
| partition-table.bin | 0x8000 | 分区表 |
| firmware.bin | 0x10000 | 应用程序固件 |

## 🚀 使用方法

### 1. 准备固件文件

将你的固件bin文件放在程序目录下,或者在 `config.json` 中指定完整路径。

### 2. 配置固件版本

编辑 `config.json` 文件中的 `firmware_version` 字段,设置你的固件版本号:
```json
{
    "firmware_version": "v2.1.5",
    ...
}
```

### 3. 运行程序

普通用户可从 GitHub Releases 下载 `AAHUB_Firmware_Flasher.exe`，并将它与配套的 `config.json`、BIN 固件文件放在同一目录后直接运行。

源码运行方式：

```bash
python esp32_flasher.py
```

### 4. 升级步骤

1. **选择串口**: 从下拉菜单中选择ESP32连接的串口
2. **点击刷新**: 如果没有看到串口,点击"刷新"按钮
3. **检查配置**: 确认固件信息和版本号显示正确
4. **开始升级**: 点击"开始升级"按钮
5. **等待完成**: 观察进度条和状态提示

### 5. 烧录前准备

- 确保ESP32已通过USB连接到电脑
- 某些板子可能需要按住BOOT键进入下载模式
- 确保串口没有被其他程序占用

## ❓ 常见问题

### Q1: 找不到串口?
**A:** 
- 检查USB线是否连接正常
- 安装对应的USB转串口驱动(CH340/CP2102等)
- 点击"刷新"按钮重新扫描

### Q2: 升级失败?
**A:** 
- 检查串口是否被占用(关闭串口监视器)
- 尝试按住BOOT键,点击RESET键进入下载模式
- 降低波特率(改为115200)重试
- 确认固件文件路径正确

### Q3: 如何修改固件版本号?
**A:** 
编辑 `config.json` 文件,修改 `firmware_version` 字段:
```json
{
    "firmware_version": "v2.0.1",
    ...
}
```
保存后重新运行程序,新版本号会显示在界面顶部。

### Q4: 如何拖动窗口?
**A:** 
点击并按住标题栏(显示"AAHUB 固件升级程序"的顶部灰色区域),然后拖动鼠标即可移动窗口位置。

### Q5: 升级过程中能关闭程序吗?
**A:** 
不能。为了保护设备安全,在固件升级过程中点击关闭按钮会弹出警告提示,程序无法关闭。必须等待升级完成(成功或失败)后才能关闭程序。

### Q6: 如何修改固件文件?
**A:** 
编辑 `config.json` 文件,修改 `firmware_files` 数组中的配置:
- 添加新文件: 在数组中添加新的对象
- 删除文件: 移除不需要的对象
- 修改地址: 更改 `address` 字段

### Q7: 如何自定义更新日志?
**A:** 
编辑 `config.json` 文件,修改 `update_log` 数组:
```json
{
    "update_log": [
        "• 修复了某某问题",
        "• 新增了某某功能",
        "• 优化了某某性能"
    ],
    ...
}
```
每条更新日志建议以"•"符号开头,重启程序后会在界面中央显示。

### Q8: 支持哪些ESP32芯片?
**A:** 
支持所有esptool支持的芯片:
- ESP32
- ESP32-S2
- ESP32-S3
- ESP32-C3
- ESP32-C6
- ESP32-H2
- ESP8266

修改 `config.json` 中的 `chip` 字段即可。
